# 心理测评题库与可交互测评站点

一个**配置驱动**的选择题测评项目：411 个测评主题、10,875 道原创题目、1,265 个测量维度、3,986 个分数段解读，全部打包为可离线双击打开的单文件网页，并附总集成导航页与 Excel 题库配置表。

> **在线体验**：<https://chenzhuanxin.github.io/psyctest-assessments/>（GitHub Pages，已启用 HTTPS）

## 目录结构

```
index.html                 总集成导航（411 个测评，分类/搜索/风格筛选/随机）
web/                       411 个独立测评页（P001-P391 来自 psyctest 主题体系，L001-L020 为学习力专题）
data/                      与网页一一对应的题库配置 JSON（可用于页面内「导入测评」或二次开发）
excel/                     题库配置表（题目/选项分值/维度/分数段，公式自动汇总）
  01_..._1799条.xlsx        psyctest.cn 全站 1799 个测评的标题与完整简介
  02_..._391个.xlsx         归纳出的 391 个测评主题（14 个一级域，含关联测评数与示例）
  03_..._题目维度分数段.xlsx  391 主题的 10,275 道题、1,186 维度、3,689 分数段
  04_学习力_...xlsx          学习力 20 主题的 600 道题、79 维度、297 分数段
tools/                     生成与校验脚本、引擎模板、出题规格
tests/                     Playwright 端到端验证脚本
```

## 使用方式

- **直接浏览**：双击 `index.html`，或把整个仓库部署到任意静态站点（GitHub Pages 亦可，路径均为相对链接）。
- **单个测评**：直接打开 `web/P001.html`（MBTI 16型人格，88 题）等任意文件，无需网络、无外部依赖。
- **作答与结果**：分页答题 → 提交后得到总分与得分率、总体评级、维度雷达图、各维度分数段解读与建议、逐题回顾，可复制文本、下载 JSON 报告、下载/导入作答存档、打印为 PDF。
- 作答数据只存在于页面内存中，**不使用任何浏览器存储 API，不上传服务器**。

## 换一个测评只要换一个 JSON

`data/*.json` 与网页内嵌数据同构：

```json
{
  "id": 5, "code": "P005", "domain": "人格与个性", "theme": "艾森克人格EPQ",
  "style": "情景选择",
  "questions": [
    {"no": 1, "type": "单选", "dim": "D1", "text": "题干",
     "options": [{"label": "A", "text": "选项", "score": 3}]}
  ],
  "dimensions": [
    {"code": "D1", "name": "内外向", "desc": "维度说明",
     "bands": [{"min": 8, "max": 13, "level": "低位", "analysis": "解读", "advice": "建议"}]}
  ]
}
```

生成新页面：

```bash
python tools/gen_site.py                       # 重新生成整站（411 页 + 导航）
python tools/build_html.py data/P005.json      # 只生成单个测评
```

计分口径（引擎不区分正反题，纯按选项分值累加，因此任何题目组合都能算分）：

- 单选题：所选选项分值；情景/趣味题选项分值为 1..n 的排列
- 频率自评：锚点固定「从不/偶尔/经常/总是」= 1/2/3/4，反向陈述题为 4/3/2/1
- 多选题：所选选项分值累加，单题满分 = 正分选项之和
- 知识问答：正确项 1 分、错误项 0 分，维度分即答对数
- 维度得分范围、总分区间由 Excel 内 `SUMIFS/COUNTIFS` 公式自动汇总

## 题目选项已随机化

`tools/shuffle_options.py` 以主题为种子打乱选项顺序并按新位置重新标注 A/B/C/D/E，分值随文本一起移动，因此维度分值区间与分数段完全不受影响。打乱后 7,972 道内容型题目的高分选项位置分布为 A 24.1% / B 25.1% / C 25.4% / D 25.5%，消除了「正确或高分项总在 A / D」的位置线索。频率自评量表的四级锚点保留语义顺序（属量表刻度而非位置线索）。
