# 测评出题规格 SPEC（子代理必读）

你（子代理）的任务：为指定主题编写原创心理测评问卷，每个主题输出一个 JSON 文件到 `questions/` 目录（工作目录即本文件所在目录）。严格遵守本规格。

## JSON 格式（UTF-8，无注释，无尾逗号，文件名 {id:03d}.json）

```json
{
  "id": 7,
  "domain": "恋爱与亲密关系",
  "theme": "主题名称（与分配清单完全一致）",
  "style": "情景选择",
  "questions": [
    {"no": 1, "type": "单选", "dim": "D1", "text": "题干",
     "options": [{"label": "A", "text": "选项文本", "score": 3},
                 {"label": "B", "text": "选项文本", "score": 1},
                 {"label": "C", "text": "选项文本", "score": 4},
                 {"label": "D", "text": "选项文本", "score": 2}]},
    {"no": 2, "type": "多选", "dim": "D2", "text": "题干（多选题须在题干末尾注明（多选））",
     "options": [{"label": "A", "text": "...", "score": 2},
                 {"label": "B", "text": "...", "score": 0},
```

## 题量与结构硬性要求

1. 题目数量 = 分配清单给定的 size，不得多也不得少；题号 no 从 1 连续编号。
2. 题型只能是"单选"或"多选"（单选为主）；每个主题至少 1 道多选，多选数量 ≤ 题目数的 20%。
3. 维度 2-5 个：size≤20 用 2-3 个维度；21-35 用 3 个；36-60 用 3-4 个；>60 用 4-5 个。
4. 每个维度至少 3 道题，维度间题量尽量均衡；dimensions 里 code 与 questions 的 dim 一一对应，不得出现未引用维度。
5. 题干 12-40 字；选项文本 6-30 字。

## 四类风格（style 字段，按分配清单执行）

### 1. 频率自评（心理/情绪/自评量表类）
- 题干为第一人称陈述句（"我最近睡眠不好"），选项文字固定四档："从不""偶尔""经常""总是"。
- 正向题分值 从不=1 偶尔=2 经常=3 总是=4；反向题（陈述消极内容）分值反转 4/3/2/1。每个维度至少 2 道反向题（即选项顺序仍是从不/偶尔/经常/总是，但分值为4/3/2/1）。
- 全部为单选。

### 2. 情景选择（人格/恋爱/婚姻/人际/职场/金钱/性心理/成长类）
- 题干为具体情境（"会议上你的方案被当众质疑，你通常会…"），选项为四种不同反应。
- 每道单选题 4 个选项分值恰为 1/2/3/4 的一个排列（顺序打乱，不得都是A=1）；分值高=该维度表现越强（得分越高越好解读）。
- 多选题：题干"以下哪些更符合你（多选）"，选项分值取 0/1/2（无则0）。

### 3. 轻松趣味（趣味人格/投射/运势类）
- 语气轻松活泼，可用假设场景（"醒来发现自己在陌生岛屿，第一件事…"）。
- 单选分值规则同情景选择；题目要有画面感与娱乐性，但主题关联必须准确。

### 4. 知识问答（城市知识/明星粉丝/科幻/智商逻辑等）
- 题干为问题，选项为 4 个候选答案；单选题恰 1 个正确选项（正确=1 分，其余 0 分）；每主题至少 2 道多选题，多选题正确选项若干（各 1 分），错误选项 0 分。
- 知识必须准确可靠，没有把握的知识点必须换题，不得编造；智商/逻辑类出数列、找规律、文字推理等有唯一正确答案的题目。
- 维度按知识领域划分（如城市知识：历史地理/美食风物/现代发展）；分数段 level 固定为：不及格/及格/良好/优秀。

## 维度分数段规则

- 每维度 bands 3-5 段（知识类 4 段：不及格/及格/良好/优秀）。
- 区间必须连续无缝、无重叠，完整覆盖 [维度最低分, 维度满分]。最低分=该维度各题选项最低分之和；最高分=各题最高分之和。写 bands 前先自行按题目算好这两个数。
- level 用简短评级词（如 低位/中位/高位，或 低/中/偏高/高，知识类固定四档）。
- analysis：该分数段人群的典型特征解读；advice：具体可操作的建议。各 40-90 字，不得雷同，不得使用绝对化诊断表述。

## 内容质量红线

1. 全部原创：不得照抄任何真实量表原文（可借鉴维度思想自编题目）。
2. 心理健康类（抑郁/焦虑/恐惧/成瘾等）只描述行为与感受，不得出现自伤方法等有害内容；分数段分析用语用"倾向""建议关注""如持续影响生活建议寻求专业帮助"等非诊断表述，且最高分段必须包含"建议寻求专业人士（心理咨询师/医生）评估"的提示。
3. 性与性别主题题目保持科学、克制、不带羞辱性措辞。
4. 题目必须贴合主题含义，禁止跑题凑数；同一主题内题目不重复、不互相暗示答案。
5. 不使用 emoji；不写"测测你""快来测"之类的营销话术进题干。
